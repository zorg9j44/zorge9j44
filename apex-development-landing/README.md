# Apex Development — Landing Page

Одностраничный лендинг для девелоперской компании «Apex Development». Готовая HTML/CSS/JS вёрстка, без сборки и зависимостей — просто открыть `index.html` в браузере.

## Структура страницы

1. **Header** — фиксированное меню, телефон, CTA «Записаться на показ», мобильное бургер-меню
2. **Hero** — главный экран с фоновым фото ЖК, заголовком, CTA и карточкой флагманского проекта
3. **Stats** — ключевые показатели компании (годы на рынке, сданные ЖК, семьи, срок сдачи)
4. **Advantages** — 6 причин выбрать Apex Development
5. **Catalog** — каталог из 6 объектов (карточки с фото, классом, метражом, ценой)
6. **Process** — 4 шага покупки квартиры
7. **Booking** — форма бронирования/записи на показ с валидацией полей
8. **FAQ** — аккордеон с частыми вопросами
9. **Footer** — контакты, ссылки, соцсети

## Стиль

- Глубокий синий (`--navy-900`, `--navy-800`) — доверие и надёжность
- Яркий оранжевый (`--orange-500`) — акценты и конверсионные элементы
- Шрифты: Playfair Display (заголовки) + Manrope (текст), Google Fonts
- Полностью адаптивна: desktop / tablet / mobile, с мобильным меню
- Фото ЖК и интерьеров — с Unsplash (прямые ссылки на images.unsplash.com)

## Использование

Просто откройте `index.html` в браузере — внешние зависимости только Google Fonts и изображения Unsplash (нужен интернет для их загрузки).
