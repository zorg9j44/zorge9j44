# Нейро-РОП

AI-ассистент руководителя отдела продаж для инфобизнеса. Веб-кабинет (Next.js на Vercel) + воркер на VPS (анализ Telegram-переписок через Claude, live-подсказки, авто-дожим, ежедневная сводка).

## Структура репозитория

```
/                  Next.js 15 (App Router) - веб-кабинет, auth, биллинг
/supabase/migrations  SQL-схема БД
/worker            Node.js воркер для VPS - Telegram, очередь, анализ Claude
/_archive_stroy_master  Старый несвязанный лендинг (архив, не трогаем)
```

## Что нужно для полного запуска

1. **Supabase проект** - создать на supabase.com, применить `supabase/migrations/0001_init.sql` (SQL Editor или `supabase db push`)
2. **Vercel** - подключить репозиторий, задать env-переменные из `.env.example`
3. **ЮKassa** - магазин + секретный ключ (нужно юрлицо/ИП)
4. **Anthropic API key** - console.anthropic.com
5. **Telegram Bot** - создать через @BotFather, получить токен
6. **Telegram API ID/Hash** - my.telegram.org (для User API, нужны для воркера)
7. **VPS** - 5.42.114.51, Node.js 22+, PM2 или systemd для процесса воркера

## Веб-приложение (Next.js)

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev
```

Деплой: подключить репозиторий к Vercel, задать те же env-переменные в настройках проекта, задеплоить ветку.

## Воркер (VPS)

```bash
cd worker
npm install
cp .env.example .env   # заполнить ключи
```

Переменные воркера включают `SESSION_ENCRYPTION_KEY` - сгенерировать через `openssl rand -hex 32`, используется для шифрования Telegram-сессий менеджеров (это фактически пароли от их аккаунтов).

### Подключение Telegram-аккаунта менеджера (User API)

Разовая операция для каждого менеджера, выполняется на VPS:

```bash
cd worker
npx tsx src/telegram/createSession.ts
```

Скрипт запросит номер телефона, код из Telegram и пароль 2FA (если включён), выведет зашифрованную session-строку. Её нужно вручную вставить в таблицу `telegram_sessions` (manager_id + session_string_encrypted + phone).

⚠️ **Риск ограничений Telegram**: подключение через личный аккаунт — не официальный API. Для снижения риска бана: не логиниться повторно без необходимости, использовать отдельный прокси на сессию при масштабировании, не подключать больше 1 аккаунта с одного IP без прокси.

### Подключение бота уведомлений

Менеджер или собственник переходит по диплинку `https://t.me/<имя_бота>?start=manager_<managerId>` (для менеджера) или `?start=owner_<companyId>` (для собственника) и нажимает Start — воркер (`src/telegram/botPolling.ts`) автоматически привязывает Telegram-чат к записи в БД.

### Запуск воркера

```bash
npm run build && npm run start   # продакшн
# или
npm run dev                       # разработка, с автоперезапуском
```

Рекомендуется через PM2: `pm2 start dist/index.js --name neuro-rop-worker`.

## Известные ограничения MVP

- CRM (AmoCRM/Bitrix24) и звонки (Whisper) - фаза 2, не реализовано
- Юридическая оферта на обработку переписок клиентов - не реализована, нужна перед публичным запуском
- Подключение Telegram-сессии менеджера - вручную через CLI-скрипт на VPS, без веб-UI
